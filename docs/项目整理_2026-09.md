## 一、目录结构与每文件作用

### 根级
| 文件 | 作用 |
|---|---|
| `bot.py` | NoneBot 启动入口：init→register OneBotV11→load_plugins |
| `memory_manager.py` | **根级**长期记忆（user_memory/long_term.json）：卡片读写/merge/格式化/提取 prompt。被包内 memory.py 经 sys.path 导入再 re-export |
| `README.md` / `ROADMAP.md` | 对外文档 / 交接+版本史（**多处停在 2026-08，见 F）** |
| `启动.bat` | 起 GPT-SoVITS api + bot 两窗口 |

### 运行时 `src/plugins/chatbot/`
| 文件 | 作用 |
|---|---|
| `__init__.py` | 事件入口：聊天主处理、心跳/在线信号(data/heartbeat|qq_alive|qq_offline)、自动通过好友 |
| `core.py` | 主循环：`build_message_list` 十层注入 + `handle_chat` 流水线 + 生成/记忆提取/防复读防措辞固化 |
| `chat_window.py` | 读秒攒批窗口（群=整群一窗），回复前读图+归纳，语音优先，分批发送 |
| `reply_style.py` | 纯函数：拆句/分批延迟/clean_reply/复读与措辞固化检测/第三人称自指保护 |
| `retrieval.py` | 六路检索+RRF+预算截断+关键词门；行为走 LLM L3+判别词（不走 embedding） |
| `routing.py` | 硬路由：legendary 梗库双路由 + L3 行为意图分类 |
| `persona.py` | 人格/terms/schedule 加载；trigger 向量加载(**已无人调用，见 B1**) |
| `memory.py` | 短期记忆(short_term.json 带锁) + re-export 根 memory_manager 长期 |
| `session_memory.py` | 会话记忆(session.json 话题/事件)+指代补全 |
| `group_memory.py` | 群记忆(groups.json 成员 id→昵称 + 群近况 events) |
| `rag.py` / `config.py` / `constants.py` / `context_probe.py` / `vision.py` | 向量工具 / 配置+客户端工厂 / 常量集中 / 时间天气感知 / 视觉 |

### persona 数据层
| 文件 | 内容/谁读 |
|---|---|
| core/system_prompt.txt | 核心人格提示词（68行，V2）**唯一 base，每轮常驻——偏规则堆叠（见 A）** |

| behavior/behaviors.json | 8 条行为(trigger/response/samples/evidence)，L3 分类+命中注入 |

| speech/voice_samples.json(+_vectors) | 86 条声音样本 few-shot（源+向量缓存，运行时读缓存） |
| speech/phrases.json(+_vectors) | 11 组措辞指纹（源+缓存） |
| world/terms.json | 名词库 28 条（lorebook：meaning/category/aliases/pattern/reaction/usage） |
| world/preferences.json(+_vectors) | 偏好 25 条（**源与缓存不一致，见 C1**） |

| world/schedule.json | 周表+近况（人肉+OCR 半自动） |

## 二、问题总清单（按主题 + 优先级 + 清理安全度）

### A. 方法论核心违背 —— 提示词塞台词/例句/堆规则（动行为，需你定）
- **A1【高】`system_prompt.txt` 把"固定台词"写进规则**：L13/17 身份必答"是永远16岁的风纪委员哦"、L18、L19、L62 `wqndyd`（与 terms 重复）、L64-68【脆弱时刻】整段（trigger+脚本+4条原话 = 该做成 behaviors 第 9 条）、L59-62【行为底色】（把 behaviors 8 条压成规则，与命中后注入的行为指令重复一遍）。
- **A2【高】同一件事三层打架**：括号纪律（system_prompt + core.py:422 注入 + clean_reply）、省略号（提示词 + clean_reply）、自指她/他（提示词 + clean_reply）各三层；**直接矛盾**：system_prompt L33"长度看内容不卡数字" vs core 每轮"【回复节奏】30字内"×2。
- **A3【中】core 注入文本内嵌示范台词**：corpus 背景段硬编码"迟到/鸽"规则+三句原话(363-369)；纯表情分支 emoji_hint 内嵌示范句+规则(454-461)。

### B. 死代码 / 死机制（清理安全）

- **B2【中】群聊"点名才回"死参数**：`_is_addressed`/`GROUP_MENTION_WORDS`/`mentioned`/`__init__` 的 `is_at_me` 全无调用（行为已回退成整群攒批），注释互相矛盾。
