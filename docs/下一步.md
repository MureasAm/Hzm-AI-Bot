## 下一步（P0）：短期历史的时间跨度

**现象**（用户 598031963）：

- 11-07 23:28 她发过“十一点半测试麦克风和小玩mc…”；
- 11-08 21:14 主动说“灰泽满要睡了，今天难得早睡，明天见”；
- 对方问“不播了吗”，她答“本来是要睡的，结果又精神了，就开一会儿测个麦”，
  把 **22 小时前**的测试麦计划当成了今晚的事。

**根因判断**：

- 短期历史行只有 `[22小时前]`，没有绝对日期/日界线；模型把跨天历史当成同一场。
- session topic 早已按 3h 过期，但 history 仍原样带着昨天的计划；`self_speech` 转述保留了
  `[X前]` lead，模型仍没用起来。
- `prev_session` 虽有“上次聊过”，但当前轮仍把昨天计划混进了“今晚”。

**建议修法**：

1. `memory.get_user_history_timed` 的历史行改成绝对日期 + 相对时间，例如
   `[11-07 23:28｜22小时前]`；或在跨天处插入 `【11-07（昨天）】/【11-08（今天）】` 分隔。
2. 历史/动态段增加一句：“跨天记录不是现在；对方问‘今晚’以【当前时间】为准。”
3. 最后一条历史超过 N 小时（如 6h）时，动态段必须保留“上一场在昨天…”的时间定性；
   检查 `prev_session` 是否在 session 更新前取到。
4. 验收：回放 598031963 这两轮，不能再把 11-07 23:28 的测试麦当成 11-08 今晚；
   跑 `pytest -q` 和 `run_tool.py regression --check`。
