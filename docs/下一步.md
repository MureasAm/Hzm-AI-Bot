### 1. DeepSeek harness 的语义理解、多次调用、思维链 —— 有没有值得学的

**链路索引**

- 一轮对话的调用构成：`chat_window._flush` → `core.handle_chat` →
  `core._fill_retrieval`（`routing.classify_l3` 行为分类 ｜ `session_memory.probe_session` 话题探测 ｜
  `corpus_judge.judge_corpus` 直播记忆判）→ `core.build_message_list`（21 个注入块）→
  `core.generate_reply`（主回复 1 次）→ `memory_v2.extract_and_ingest`（异步记忆提取）。
- 工具轮：`tool_loop.generate_with_tools`（开关 `RECALL_TOOLS` / `TOOL_PROBE` / `TOOL_CAPABLE_MODELS`；
  账本 tag = `工具选择`，现在约 52 次/天）。
- 思考参数：`constants.THINKING_DISABLED`（全局默认关）、`constants.MODEL_EXTRA_PARAMS`（按模型名查表）、
  `config._ChainCompletions.create` 按层覆盖。
- 用量与分账：`data/llm_usage.jsonl`（`tag`/`route`/`hit`/`miss`/`output`/`ms`）、`scripts/llm_cost.py`。
- 实测基线（最近 7 天）：一轮 ≈ 4 次调用（主 1 + 辅 3.9）；输入 token 主回复 3,045、
  行为分类 2,572、记忆提取 4,510、话题探测 1,921。

**要回答的问题**

- 哪些判断值得给"思考预算"？候选：直播记忆判（判断"用户是不是在问她这段经历"）、术语消歧。
  已实测：主回复开思考只能换来 才 10%→0%、起手 35%→30%，代价是输出 token 7 倍、延迟 +600ms。
- 哪些可以**合并成一次调用**？话题探测与行为分类同基于"用户这句话 + 历史"，
  现在各花 1,900~2,600 输入 token，合并后每周能省 5~8M 积分。
- 工具轮值不值得常态化：现在只有 `recall` 一个工具、触发率极低；
  harness 的"先规划再动手"在 QQ 单轮回复里是不是等价于"多一次调用"。

### 2. GPT-SoVITS 语音：单字拉长 / 丢失尾音

**链路索引**

- `voice.py`：`should_voice`（长度/语种闸门）→ `_tts_text`（清洗：剥括号、去符号、破折号转停顿、
  `hzm`→灰泽满）→ `_pick_tier`/`_resolve_ref`（参考音频与情绪档）→ 合成 →
  `_clean_wav` / `_speech_seconds` / `_wav_duration` → `_is_acceptable` / `_quality_score` → 发送。
- 参考音频：`constants.SOVITS_REF_DIR` = `assets/voice_refs/`（`ref_voice.wav` + 同名 `.txt`；
  情绪档 `ref_happy` / `ref_lazy` / `ref_serious` 可选）。⚠️ CLAUDE.md 记的坑：**参考音频必须无尾静音**。
- 外部服务：`env\python.exe api_v2.py`（GPT-SoVITS，端口 9880）。
- 硬参数：`_TTS_TEMPERATURES`(0.8/0.95/0.85)、`_TTS_BUDGET_SEC`(45s)、`_TTS_ATTEMPT_TIMEOUT_SEC`(30s)、
  `_expect_seconds` / `_bloat_limit`（预期时长 vs 实际时长）。
- 现成样本：`data/voice_cache/`。

**要查的**

- 先分层定位：用 `data/voice_cache` 的成品 + whisper 转写，对比"原文 → `_tts_text` 输出 → 转写"，
  判断丢尾音发生在**文本层**（`_tts_text` 的正则把尾字/末尾标点吃了）还是**合成/剪切层**
  （`_clean_wav` 的静音裁剪把尾音剪掉）。
- 单字拉长多在哪个音上（句末语气词"啊/哦/啦"？），是不是参考音频语速或某档情绪参考导致；
  换 `ref_serious` 对同一句做 A/B。
- 合成参数是每句随机挑温度（0.8/0.95/0.85），先确认是不是某个温度档系统性拉长。
