## 0. 尺子的全景

### 0.1 三把还立得住的尺子

| 层 | 尺子 | 判据性质 | 状态 |
|---|---|---|---|
| **检索层** | `retrieval-eval`（`retrieval_eval_cases.json`，48 条 query→期望） | 人定：这句话该不该命中某路 | ✅ 立得住 |
| **生成层** | `regression --check`（`regression_cases.json`，7 条真实翻车固化） | 确定性：禁词 / 开头同质率 / 逐字复读率 | ✅ 立得住 |
| **内容正确性** | 消融（`section_correctness` / `schedule_ablation` / `situation_ablation`） | 客观对错：她答的时间/事实对不对 | ✅ 立得住 |

三把的共同点：**判据有客观真值、能失败、只变一个变量、可复现**。内容正确性那条尤其硬——
答案就在文件里（"她答的时间是否等于 `schedule.json` 的值"），不需要任何模型来懂她。

### 0.2 风格层这把尺子的教训：三条路全废 → 路线停用

"像不像她"没有唯一正确答案，这一层换过三把尺子，**三把都废**：

| 版本 | 尺子 | 为什么废 |
|---|---|---|
| v1 | 长度 / 括号 / 叹号率 | **指标没对准被测对象**——那是骨架管的，不是 traits/styles |
| v2 | **指纹距离**（与她本人 620 条真实回复的距离） | **噪声 ≥ 信号**：baseline 两次运行自己波动 **0.03**，而效应量只有 0.01~0.06 → 两版安慰剂给出**相反判定** |
| v3 | **LLM 成对比较**（"哪句更像她"） | 裁判**不知道灰泽满是谁**，只见过塞给它的 20 句；42/42 校准只能分辨"她 vs 客服腔"这种大差别 |

**第四种尝试（把"像不像她"固化成标注数据）也停了**（2026-09-30）：
用户标了 30 条 → **23 道成对题里 20 道判"差不多"（87%）**。原因不是文件没用，
而是两版同模型、同 base，差异落在人眼可判范围以下；而"用人判"本身还需要一个已知大小的校准差，**形成自指**。
→ **路线停止，工具已删**（`style_annotate.py` / `style_eval_cases.json` / `pairwise_style.py`），见 `docs/历史/已删机制登记.md` §10。

**现在的替代口径**（内容用对错、风格用可数特征、行为用情境动作率）：

- 内容类 → 答对率
- 形式类 → 可数特征（自称率 / 省略号率 / 长度…）
- 行为类 → 情境动作率
- 整块人格 → 压缩成本对照 / 是否需要身份框架这类结构性对照

### 0.3 一把尺子要满足什么才算数

从本仓反复翻车里蒸馏出的检查项（写判据前逐条过）：

1. **有客观真值**——答案在文件里，不是我编的期望。
2. **能失败**——「**如果她答错了，这个判据会通过吗？**」会通过的就不是判据，是噪声。
   （踩过：偏好判据放了 `猫|怕`，她说"不喜欢猫"也过 → 两侧 100%；terms 放了 `绿冻` → 两侧都出现；
   时间只认阿拉伯数字 → 她写"七点多"被判 0。）
3. **只变一个变量**——其余一字不动。
4. **先验尺子再用**——`persona_fingerprint --validate` 就是先拿"明显不像她"的对照看尺子能不能推开。
5. **报显著性**——只报"选中率 + 二项检验 p"，**50% 附近一律读作"分不出"**。
6. **安慰剂对照**——"删掉一段 → 输出变了"不能证明那段内容在起作用，因为**删任何段都会让上下文变短**。
   要把内容换成**等长无关文本**再比。
7. **净作用 = 基线 − 裸模型**（2026-09-30 补）——之前所有读数**都没减过模型先验**，可能有一半要重算。

**证据强度分级**（本文每条按此标）：**强**（客观真值+能失败+只变一个变量+差异压倒性）／
**中**（前三条满足但样本小）／**弱**（代理指标，只量"影响"不量"价值"）／**测不了**（判据覆盖不到）。
⚠️ 「**影响**」（拿掉它，输出会变）≠「**有价值**」（有它比没有更好）。

### 2.7 情境动作率（含裸模型下界）—— `situation_ablation.py`

衡量"性格基底/behaviors 这类**行为文件**"的读数（不是"她怎么打字"，是"她遇什么事怎么做"）。
8 条/情境，看"她做了那个动作没"：

| 情境 | 基线 | 裸模型（只有身份） | 读法 |
|---|---|---|---|
| **被夸** | 7/8（87.5%） | **8/8（100%）** | 裸模型本来就做 → **没有信号**（先验） |
| **被示好** | 1/8（12.5%） | **6/8（75%）** | 裸模型做更多 → 基线被压制，异常 |
| **让立flag** | 2/8（25%） | 1/8（12.5%） | 差 1 条，噪声 |
| **被捧高** | 3/8（37.5%） | **0/8（0%）** | 真实信号（裸模型不做，基线做了） |

✅ 算数，且带出两条方法论：
1. **净作用 = 基线 − 裸模型**：之前所有读数**都没减先验**（含形式特征的基线），可能有一半要重算。
2. **留一法表**：同一个动作可能由多份文件共同支撑，一次只删一个文件各数一次，"谁在扛这个动作"就写在表上。

### 2.8 形式：同一事实写成不同形式会怎样 —— `form_experiment.py`

事实=「最喜欢的数字是 7」，各 16 次。**两个观测量：采用率、逐字复读率**：

| # | 形式 | 采用率 | 逐字复读率 |
|---|---|---|---|
| ① | 不注入（基线） | 9/16（瞎猜） | 0/16 |
| ② | system 第三人称陈述（corpus） | 16/16 | **10/16** |
| ③ | system 事实条目（preferences） | 16/16 | 5/16 |
| ④ | system 词表（**自足**） | 16/16 | **16/16** |
| ⑤ | system 指令式（behaviors） | 16/16 | **16/16** |
| ⑥ | **assistant 问答对**（原 voice_samples） | 15/16 | **0/16** |
| ⑦ | system 碎片词表（**不自足**） | 5/16 | **0/16** |
| ⑧ | 同 ④，换成 corpus 式包装 | 16/16 | **16/16** |
| ⑨ | 问答对·user 改情境描述 | 16/16 | 0/16 |
| ⑩ | 只有 assistant（无配对 user） | 16/16 | 7/16 |
| ⑪ | system 纯情境描述 | 16/16 | **15/16** |

**三条结论**：
1. **传不传得进去从来不是问题**——只要注入了，内容就进得去（②~⑥ 全 15~16/16）。
2. **真正分得开形式的是"会不会被整句搬走"**：**自足 → 被整句抄；不自足 → 织进新句；问答对 → 又传得进又不逐字**。
3. **包装语无效**：⑧ 与 ④ 内容一字不差、只换包装（明写"别整段复述"）→ **逐字率一模一样 16/16**。
   "刚说过"副作用：⑥ 8/16、⑨ 12/16、⑩ 1/16、⑪ 0/16。

✅ 算数（确定性读数）。**通道 vs 位置**：同一事实走 assistant turn **3/5 被采用**、走 system 说明 **0/5**——
"她本人的话"比任何 system 说明都强（**但别外推成"所有 system 都没用"**，这条只管"作风"，不管"信息"）。

该换判据为「融合+截断后期望的条目还在不在」。

### 2.13 时间感知：注「时间量」vs 注「状态推论」（2026-10-05）

**背景**（用户提的）：大模型没有时间感知，只有上下文。「隔了两小时回来」时它不会自然代入，
只在被提起时间时才意识到——但一提时间就机械。

**实验**（`outputs/_experiments/_exp_time_state.py`）：场景「历史停在"21:00 开播前顺稿子" →
隔 2 小时（直播早过了）→ 用户说"来了"」，三档各 20 次：

| 档 | 注入什么 | 自然接上"直播已过" | 误判"还没开播" |
|---|---|---|---|
| ① 时间量 | 「距上轮已经过去2小时」 | **14/20 = 70%** | 0/20 |
| ② **状态推论** | 「那场直播现在应该已经结束了」 | **19/20 = 95%** | 0/20 |
| ③ 都给 | 两条都注 | 17/20 = 85% | 0/20 |

**结论**：
1. **注"状态"远比注"时间量"有效（95% vs 70%）**——人不是感知时间，是**通过时间推出状态**
   （"哦，直播该结束了"），所以该给的是推论，不是时长。
2. **两条一起注反而更差（85%）**：时间量会把她引向**评论时间**（"都这会儿了"），
   状态会引向**评论处境**（"你才来"）——**前者在抢注意力**。
3. 两档都 0/20 误判，方向是安全的。

⚠️ **未能推广**：能可靠推出的状态很少（**直播**最确定，因为有周表固定时间；
作息/约定只有一半；"那两小时里她自己在干嘛"推不出来）。所以这条路的价值集中在直播这一个例子。

⚠️ **样本同质**：② 档里「刚下播，累死了」重复约 5/20——"自然度"要打折。

### 2.14 会话记忆：旧话题不再被当"当前"（2026-10-05）

**背景**（用户指出的结构问题，比上面那条更根本）：

> 「会话级记忆的更改是由模型有没有检测到新的话题而改变的，**但不会随时间改变**。
> 但正常聊天时，一般过去几个小时这个话题就是自然结束的状态。
> **关键问题就是过了很久再回来说话的会话依旧是上次的主题。这才是割裂感的根源。**」

**实测确认**（`outputs/_experiments/_exp_session_gap.py`）：旧代码里

| 隔多久 | 注入成什么 | 有没有时间定性 |
|---|---|---|
| 10 秒 | 【当前会话】当前话题：香水 | ❌ |
| **3 小时** | 【当前会话】当前话题：香水 | ❌ **和上面一模一样** |
| 14 小时 | 【上次聊过】14小时前你们聊到「香水」 | ✅ |

**根因**：时间挂错了地方——`get_session` 的 12h 阈值只决定"丢不丢"，
**`build_session_context` 注入的文本里根本没有时间**，还断言"当前话题/本场发生"。

**改法**（用户定：不设阈值、让模型自己判）：
1. 记 `topic_since`（话题**什么时候开始的**）——因为 `last_active` 每轮刷新，
   只等于"距上一条消息多久"，**不表示话题有多旧**；
2. 注入改为陈述事实：`【会话记忆】话题：…（这个话题是3小时前开始的）/ 期间：…`，
   **去掉"当前/本场"**，判断交给模型；
3. 阈值 12h → **24h 且改按话题年龄判**（只当"很久了、连记录都不值得提"的兜底）。
   ⚠️ 原来看 `last_active`，所以那个兜底**永远不会触发**（每轮刷新）——修完才真的生效。
4. **每条历史消息自带 `[3小时前]`**（`memory.get_user_history_timed`），
   并**喂给 L3**——它判 `same_request`「连续第几轮」时必须知道那几轮之间隔了多久。
   改后 behavior 仍 **18/18**（判据未见退化）。

## 附：用户画像注入实验（2026-10-10，脚本 `scripts/profile_experiment.py`）

**问题**：把"用户的性格"注入进去，到底改不改回复？该用**标签**（"讨好型人格"）还是**行为句**
（"她自责时先接住情绪"）？

**方法**：同一句真实用户消息、只差注入那一块，四种生成——
`A`=不注入 / `A2`=**同条件再生成一次** / `B`=注入性格标签（v1 印象原样）/ `C`=注入同一批印象改写的行为句。
36 轮真实对话，素材取 v1 记忆卡里 25 个有印象标签的用户。

**关键设计：`A2` 噪声地板。** `CHAT_TEMPERATURE = 0.85`，**同一条 prompt 两次生成也会差很多**。
没有 `A2`，就会把采样噪声当成"注入的效果"（上一版常驻实验正是这么判不出来的）。

**结果**（文本相似度，1.0 = 一样）：

| 对比 | 相似度均值 | 配对检验 |
|---|---|---|
| `A vs A2`（**噪声地板**） | 0.391 | — |
| `A vs B`（标签） | 0.301 | 比地板远 +0.090，**t=+1.91** |
| `A vs C`（行为句） | 0.358 | 比地板远 +0.034，**t=+0.85** |
| `B vs C` | 0.342 | 标签 vs 行为句 −0.056，**t=−1.45** |

长度三档几乎相同（20.7 / 20.6 / 20.4）；三档都没把标签念出来（泄漏率 ≤3%）。

**结论**：
1. **注入用户性格，回复的变化没有超过采样噪声**（标签档 t=1.91、行为句档 t=0.85，都没到 2）。
   → **不做"性格常驻"层**；v2 里也没有必要为此加一个 kind。
2. **标签 vs 行为句分不出来**（t=−1.45）。→ 真要做，**直接用标签就行**：
   黄金律 #2（行为 > 标签）是为**她自己的话**写的——标签不告诉模型她自己该说什么；
