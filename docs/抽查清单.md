# 回复抽查清单

> **用途**：抽查她的回复时，**对着这张表看**——而不是凭感觉。
> **来源**：CharacterEval（ACL 2024，中文角色扮演评测基准）的 13 项指标，翻译成人话。
> **为什么需要**：我们说"最终回复质量只能人看"，但**"看什么"一直没有标准**——
> 没有标准就没法判断"这轮改动到底让她变好了没有"。
>
> 用法：抽 20~30 条真实对话，逐条对着打勾。**哪一类勾最少，就是下一步该修的地方。**

---

## A. 对话能力（像不像"在聊天"）

| # | 检查什么 | 怎么算不合格 |
|---|---|---|
| A1 | **说不说得通** | 句子通顺、没有明显的语病或拼接痕迹 |
| A2 | **接不接得上** | 她这句话是针对用户**刚说的事**吗？有没有答非所问 |
| A3 | **前后矛不矛盾** | 她前面说过的事，这句里有没有自己打自己脸 |

> ⚠️ A3 是**事实层面**的矛盾，不是态度变化。态度可以变，事实不能打架。

## B. 角色一致性（像不像"她"）★ 最重要

| # | 检查什么 | 怎么算不合格 |
|---|---|---|
| B1 | **知识准确** | 她说的关于自己的事，**是对的吗**（身高/室友/作息/喜好…） |
| B2 | **知识幻觉** ★ | **她编了吗**——说了一件她根本没经历过的事，或者把某次的事当成"现在" |
| B3 | **人物行为** | 该嘴硬的时候嘴硬了吗？该认怂的时候认怂了吗？（不是"合理"，是"像她"） |
| B4 | **说话风格** | 自称对吗（hzm/灰泽满）？句子长短对吗？语气词用法像吗？ |

> ⚠️ **B2 是这套系统最容易出的问题**：
> "想起错的"比"想不起来"伤害大（她会理直气壮说一件没发生过的事）。
> 判据：**这件事她有依据吗？** 没有依据还说得斩钉截铁 = 幻觉。

## C. 角色吸引力（像不像"一个有意思的人"）

| # | 检查什么 | 怎么算不合格 |
|---|---|---|
| C1 | **像真人** | 是不是"AI 在扮演"，有没有咨询师腔/客服腔/助手腔 |
| C2 | **沟通技巧** | 有没有把话聊下去（反问/自嘲/延伸），还是干巴巴答完就停 |
| C3 | **表达多样** | 有没有反复用同一个词/同一个句式开头（复读感） |
| C4 | **共情** | 用户诉苦/撒娇时，她的反应**对得上情绪**吗 |

## D. 人格回溯（内在一致）

| # | 检查什么 |
|---|---|
| D1 | **她的立场稳不稳**——同一个人问她同一件事，答案是否在**合理范围内**波动 |
| D2 | **她的"人设"有没有漂**——有没有突然变得特别温柔/特别热情/特别配合（不像她） |

---

## 怎么用最省事

**别每次全查一遍。** 按这个顺序：

1. **先只看 B2（知识幻觉）** —— 它是最伤的问题，而且最容易一眼看出
2. 再看 **B3/B4（行为/风格像不像她）**
3. 剩下的扫一眼就行

**记录方式**：一句话就够——

```
「用户问X」→ 她答Y
  ✅ 事实对（B1）
  ❌ 幻觉：说了一件没有的事（B2）  ← 这条是重点
  ✅ 行为像（B3）
```

**攒够 20~30 条**，哪一类问题最多，就是下一步的目标。

---

## 已知的"高发区"（抽查时重点看这些）

按本仓已有的实测，这几处最容易出问题：

| 高发区 | 为什么 | 看哪一项 |
|---|---|---|
| **用旧记忆回答当下** | 素材携带具体情境会被当"现在"复用（"搬家"那个坑） | B2 |
| **想起错的** | corpus 召回判错 / 素材本身含具体措辞被照搬 | B2 |
| **复读** | 同一话题反复问时，她可能把上轮那句原样搬出来 | C3 |
| **"刚说过了"** | assistant turn 的样本被当成"刚发生过的对话" | B1/B3 |
| **编偏好** | 偏好档案没覆盖的话题，她会现场编一个立场（且不进记忆，下次可能不同） | B2/D1 |
| **45% 的轮次没有任何素材** | 只能靠 2974 字骨架答 → 容易变成"遵守规则的人"而不是"她" | B3/B4/C1 |
