# 灰泽满是怎么回复的

> 只讲四件事：**① 链路 ② 注入架构（事实型/人格型）③ 为什么这么设计 ④ 撑住它的实验数据**。
> 想查细节看 `注入链路.md`（现状）和 `注入设计原理.md`（全部实验）。
> 最后更新：**2026-09-30**

## 一、整条回复的链路

一条消息进来，到她回话出去，走这 9 步：

| # | 步骤 | 干了什么 | 在哪 |
|---|---|---|---|
| 1 | **收到** | 进"读秒窗口"——不马上回，先等几秒看他还说不说 | `__init__.py` |
| 2 | **攒批** | 安静下来后把这几条合成一批一起处理（真人也是听人说完再答） | `chat_window.py` |
| 3 | **看 / 读** | 有图片 → 先描述成文字；一批 >1 条 → 先归纳成一两句 | `vision.py`、`summarize_batch` |
| 4 | **检索** | 拿这句话去几个库里找素材（下表） | `retrieval.py` |
| 5 | **组装** | 拼出 17 段 system + 她本人的原话对 + 用户那句 | `build_message_list` |
| 6 | **生成** | 交给模型写回复 | `generate_reply` |
| 7 | **后处理** | 拆句、去括号、省略号纪律、防复读、换行归一 | `reply_style.py` |
| 8 | **发送** | 分批发（打字感）；语音优先；可能配表情包 | `chat_window._send` |
| 9 | **回写** | 写回短期记忆；异步提炼长期记忆 | `memory.py`、`memory_manager.py` |

**关键在 4、5 两步**：不是把所有素材一股脑塞进去，**是按这句话去挑**。

### 第 4 步「检索」具体在找什么

**六路**：直播经历、说话样本、行为示范、措辞 走 RRF 融合（各带权重），再按 top-6 / 1200 字预算截断；
另外偏好、核心记忆是"命中才带"。

| 路 | 找什么 | 判据 | **进不进 RRF** |
|---|---|---|---|
| 直播经历 | 她经历过的具体事件 | 向量召回 → **LLM 判「这跟用户刚说的是不是一回事」** | ✅ |
| 说话样本 | 她本人的原话 | 向量召回 | ✅ |
| 行为示范 | 什么情境做什么 | **LLM 分类**（判"这句属于哪类情境"） | ✅ ⚠️ |
| 措辞 | 同意思、她的说法 | **同一次 LLM 分类**（跟行为一起判，零额外成本） | ✅ ⚠️ |
| 偏好 | 她一贯喜欢什么 | **子串命中**（用户说到那个词） | ❌ 命中才带 |
| 核心记忆 | 印象最深的经历 | 低阈值向量召回 | ❌ 命中才带 |

⚠️ **那两行标 ⚠️ 的是个已知的架构不一致**（2026-09-30 量过，**先记着、别急着改**）：

**RRF 是为"检索"造的**（多路候选怎么融合成一份有序列表）。而
**"归类"和"关键词"的答案是「判定」（是/否），不是「排序」（谁前谁后）**——
把判定塞进排序里，它会**占 top-6 的名额**，且"该不该注入"变成"谁 rank 更前"。
**偏好（同样是判定）已经不在 RRF 里了，归类却还在** → 这就是那个不一致。

**实测代价：现在看不到。** 48 条评测里归类**挤掉率 0%**（behavior 权重 1.5 最高，
rank-1 恒压过语料；而且 top-6 名额够用）。被挤掉的 2 条反而是检索类的附带召回。
→ **所以不该现在重构**，而该**把它从"静默"变成"可见"**：
某轮"归类命中了、融合后却一条没留"时打个日志。**只在真发生时报警。**

名词库（terms）和梗库（legendary）走另一条：**子串命中**——前者命中才注入，后者命中**直接当回复发出去**（不进模型）。

## 二、注入架构：一段常驻 + 十七段按需，而素材分两类

**不是"一个提示词包"（酒馆那种），是「1 段常驻骨架 + 17 段按需注入」。**

素材按"管什么"分**两类**——这是理解整个项目的钥匙：

| | **事实型注入** | **人格型注入** |
|---|---|---|
| 管什么 | 她**知道什么** | 她**是谁 / 怎么说 / 怎么做** |
| 有哪些 | 周表、当前时间、直播经历、名词库、偏好、核心记忆、长期/短期/会话/群记忆 | 骨架、性格基底、语言风格、行为示范、说话样本、措辞、梗库、表情包 |
| **有没有客观真值** | **有**——答案就在文件里 | **没有**——"像不像她"没有标准答案 |
| **该用什么判据** | **她答对了没有** | 可数特征 / 情境动作率 / 形式三指标 |
| 现状 | ✅ 已量出，作用巨大 | ⚠️ 一部分量得出，一部分**测不出来** |

> **为什么要分两类**：因为它们的**判据根本不同**。
> 拿"答得对不对"去测人格型 → 测不出（删掉性格基底她还是答对时间）→ 会得出"它没用"的**假结论**。
> 反过来拿"像不像她"去测事实型 → 也测不出（她胡编一个时间，但胡编得很像她）→ 同样是假结论。
> **这个分类不是学术洁癖，是"两条路各自会怎么骗你"的说明书。**

### 十七段分别是哪些

| # | 内容 | 类 | 触发 |
|---|---|---|---|
| 1 | **base**（骨架 + 性格基底 + 语言风格） | 人格 | **总是**（3758 字） |
| 2 | 【灰泽满的周表】 | 事实 | 有周表就注 |
| 3 | 【灰泽满的偏好】 | 事实 | 命中才注 |
| 4 | 【她的核心记忆】 | 事实 | 命中才注 |
| 5 | 【群聊现场】 | 事实 | 群聊 |
| 6 | 【灰泽满的世界】（名词库） | 事实 | 有命中词 |
| 7 | 【当前会话】 | 事实 | 有会话记忆 |
| 8 | 【当前时间】（时间/农历/天气/直播状态） | 事实 | **总是** |
| 9 | 【当前情境下的行为指令】 | 人格 | 判中行为 |
| 10 | 【她经历过的相关背景】（直播经历） | 事实 | 检索命中 |
| 11 | 【关于这个绿冻的长期记忆】 | 事实 | 私聊 + 有画像 |
| 12 | 【最近对话记录】+【别自相矛盾】+【防复读】 | 事实 | 有历史 |
| 13 | 【她的固定说法】（措辞） | 人格 | 检索命中 |
| 14 | 【灰泽满的说话方式参考】+ **多条 user/assistant 对** | 人格 | 检索命中 |
| 15 | 【这批消息的归纳】 | 事实 | 一批 >1 条 |
| 16 | 【用户这条消息的语境】/【用户发了表情】 | 事实 | 短消息 / 表情 |
| 17 | **user**：真正的那句话 | — | 总是 |

## 三、为什么采用这样的架构

### ① 为什么按需注入，不全塞进去
常驻的骨架已经 **3758 字**，而检索层**平均只注入 125 字**。全塞的话，
322 条直播经历一次进去几十万字，直接爆掉。而且"**过去的经历只有被提起才想起来**"——
这既是记忆的本性，也正好是省预算的方式。

### ② 为什么事实型走"关键词 + LLM 判"，不纯靠向量
实测：短文本的余弦**分不出真假**。
```
措辞：噪声地板 0.575  vs  真信号 0.573   → 完全重叠（等于没有阈值，100% 开火）
偏好：噪声地板 0.565  vs  真信号 0.501/0.552/0.590 → 地板插在正例正中间
```
**根因**：措辞的触发词是 `"被夸奖、被称赞时"` 这种**类别标签**，不是句子。
拿"用户说的话"和"一个类别标签"算余弦，是**拿检索工具干分类的活**。
→ 所以按任务换工具：**归类用 LLM 分类、关键词用子串、检索才用向量+LLM 判**。
实测收益：措辞开火 **100% → 20%**、偏好 **19% → 5%**，逐条看过无误报。

### ③ 为什么人格型要分"问答对 / 碎片 / 陈述"不同形式
因为**形式决定素材会不会被整句抄走**（见第四节 E3）。同一个事实写成不同形式，
采用率都在 15~16/16，**差别全在"逐字复读率"：自足的会被整句搬走，碎片不会**。

### ④ 为什么人格型要走 assistant 通道
实测：**同一个事实**，走 assistant（她本人说过的话）被采用 **3/5**，走 system（关于她的说明）**0/5**。
"她本人的话"比任何说明都强。所以说话样本那一路值得重点投资。

### ⑤ 为什么包装语没用（这条最反直觉）
每个注入段外面都包了一句说明（"不要整段复述""请严格按此模式回应"）。实测**换了它，行为一模一样**。
```
④ 词表 + 「用这些原话组织」    → 逐字 16/16
⑧ 同④内容 + 「不整段复述」    → 逐字 16/16   ← 一模一样
```
**→ 文件的角色不写在包装语里，写在内容形式里。** 2026-09-30 已按此删掉 10 处无效包装语。

## 四、撑住这些结论的实验数据

### E1 事实型：删掉那一段，她还答得对吗 —— **作用巨大**

| 删掉 | 问什么 | 有它 | 没它 |
|---|---|---|---|
| 周表 | 明天几点播 | **88%** | **0%** |
| 当前时间 | 今天几号/星期几 | **92%** | **0%** |
| 直播经历 | 你多高啊 | **4/4** | **0/4** |

判据是"**她答得对不对**"，答案在文件里——**不需要任何人当裁判**。这是最硬的一类证据。

### E2 判据横向对比：同一份标注集上比谁最好用

| 路 | 旧方案 | 现方案 | 准确率变化 |
|---|---|---|---|
| 措辞 | 余弦 ≥0.40 | **LLM 分类** | 100% 假信号 → 开火 20%，逐条无误报 |
| 偏好 | 余弦 ≥0.55 | **子串命中** | 0.67 → **0.90**（召回 0.80 → **0.90**） |
| 直播经历 | 纯余弦 | 关键词门 + **LLM 判** | 0.60 → **0.83** |

### E3 形式对照：同一个事实写成 7 种形式，各跑 16 次

| 形式 | 采用率 | **逐字复读率** |
|---|---|---|
| 不注入（基线） | 9/16（瞎猜） | 0/16 |
| system 第三人称陈述 | 16/16 | **10/16** |
| system 词表（自足） | 16/16 | **16/16** ← 整句抄走 |
| system 碎片（不自足） | 5/16 | **0/16** ← 织进新句 |
| **assistant 问答对** | **15/16** | **0/16** ← 唯一两者兼得 |

**结论**：传不传得进去从来不是问题（都 15~16/16）；**真正分得开形式的是"会不会被整句搬走"**。
真正起作用的变量**不是"哪个文件"，是"注入的那段是否自足"**。

### E4 通道实测（支撑 §三④）

同一个事实走两条通道：**assistant 3/5 被采用 ｜ system 0/5**。

### E5 ★ 净作用 = 有文件 − 裸模型（这一轮最重要的方法）

**问题**：模型自己就会做的事，不能算到你数据头上。给她一个"被夸"：

| | 有全部人格文件 | 裸模型（只有身份） | **净作用** | 结论 |
|---|---|---|---|---|
| 被夸 → 否认 | 88% | **100%** | **−12pp** | ⚠️ 模型自带，**别为它花预算** |
| 被捧高 → 推拒 | 38% | **0%** | **+38pp** | ✅ **你的数据真的在教它** |

**同一个文档里早有同类教训**：测"挑食→不吃香菜"时，**不注入的基线也有 13/16**——
强先验被当成了注入的效果。

### E6 人格型整体：值不值这份预算

常驻那 3758 字砍到 2315 字（-38%），两版摆给用户挑：
**13 对里有 6 对有明确偏好，6 道全选原版** → **那 3758 字是值的。**

### E7 可数特征基线：把"改动有没有改坏"变成数得出来的事

数她回复里的可数特征，得到一条基线：

```
省略号率 17% ｜ 自称率 70% ｜ 问号率 25% ｜ 括号率 13% ｜ 句长 20.3
```

以后**任何改动**跑一遍，看这几个数掉没掉：掉了回退、没掉通过。
例：删掉性格基底 + 语言风格（611 字）→ **省略号率 22% → 6%**（8 对里 7 对是这个方向）。

### E8 使用率普查：素材"用得少"不等于"没用"

| 素材 | 规模 | 真实用到 |
|---|---|---|
| 直播经历 | 322 条 | 37 条（11%） |
| 名词库 | 27 条 | 3/26 |
| 经典梗 | 8 组 | 3 条 |
| 行为示范 | 11 条 | 3/11 |
| 说话样本 | 86 条 | 11/86 |

**怎么读**：很多素材是"**只有被提起才该想起来**"，没被用到是**设计如此**，不是浪费。

### E9 现行评测（每次改完必跑）

```
检索评测   run_tool.py retrieval-eval        → 47/48
判据回归   run_tool.py regression --check    → 8/8
单元测试   pytest -q                          → 765
```

## 五、一句话记住这个项目

```
① 判据按任务选     归类→LLM分类 ｜ 关键词→子串 ｜ 说法不可枚举→向量+LLM判
② 形式看是否自足   自足→被整句抄 ｜ 碎片→织进新句 ｜ 问答对→两者兼得
③ 通道比位置要紧   "她本人的话" 3/5 ＞ "关于她的说明" 0/5
④ 包装语管不住     想让模型怎么用，改形式，别加说明
⑤ 测作用要减先验   净作用 = 有文件 − 裸模型
```
