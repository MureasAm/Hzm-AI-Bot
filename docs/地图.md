## 2. 运行时核心 `src/plugins/chatbot/`（26 个文件）

### 2.1 一条消息的链路（改之前先认路）

```
QQ 消息
  → __init__.py::_handle_chat          采集 + 还原（图/引用/转发/表情/@ → 文本）
  → chat_window.enqueue                进读秒窗口（同会话消息攒批）
  → chat_window._process → _flush      静默 5~10s → 读图 → 归纳 → 群门 → 生成
      → core.handle_chat               主循环（拼 messages → 调模型 → 记忆更新）
      → core.build_message_list        注入 17 段（见 架构.md）
      → core.generate_reply            调 DeepSeek
      → reply_style.clean_reply        清洗（换行归一 / 去括号前缀 / 省略号纪律）
      → voice.should_voice → send_voice  语音优先（成功就不走文字分段）
      → reply_style.split_reply        文字分段
  → chat_window._send                  发出；chat_window._maybe_send_sticker 补表情包
```

**逐段细节、判据怎么选、为什么这么排 → `架构.md`。**

## 3. 人格数据 `persona/`（14 个文件）

**两条分类轴**（判据详见 `架构.md`）：

- **人格文件（2 个）**：`core/system_prompt.txt`（骨架，每轮常驻）、`behavior/behaviors.json`（16 条情景，命中才注）
- **事实文件（其余全部）**：她知道什么、发生过什么

| 文件 | 大小 | 条数 | 作用 | 走向量？ |
|---|---|---|---|---|
| `core/system_prompt.txt` | 9KB / **3413 字** | 8 节 | **骨架**：核心人格 / 身份 / 说话节奏 / 自称 / 括号省略号 / 行为底色 | 否（每轮常驻） |
| `behavior/behaviors.json` | 28KB | **16 条** | **行为层核心**：什么情境 → 怎么做（台词在 `samples`） | 否（走判别词 + LLM 分类） |
| `behavior/behavior_keywords.json` | 1.9KB | 3 行为 / 21 词 | behaviors 的**确定性兜底**（readme 自曝：真实 188 条对话里 0 命中） | 否 |
| `media/stickers.json` | 12.7KB | **31 张** | 表情包标注（desc/tags/use_when/group） | 否 |
| `world/statement_final.json` | 106KB | **421 条** | **事实层 corpus**：她"发生过什么"（只放事实，不放引语） | **是** → `corpus_vectors.json` |
| `world/corpus_vectors.json` | **17.0MB** | 421 条 | statement 的向量缓存（**仓库最大文件**） | 向量库 |
| `world/corpus_asks.json` | 68KB | **181 条** | 每条 corpus 的"用户可能怎么问"（入口工具，不进提示词） | 间接参与检索 |
| `world/corpus_keywords.json` | 48KB | **421 条** | corpus 的**钩子**：用户提到这些词 → 递候选 | 否（是门） |
| `world/preferences.json` | 8.2KB | **23 条** | **是这样的人**：去掉"某次直播"仍成立的事实 | 否（按 keywords 子串命中） |
| `world/core_stories.json` | 3.5KB | **5 条** | **记得（最深处）**：印象最深的经历 | **是** → `core_story_vectors.json` |
| `world/core_story_vectors.json` | 229KB | 5 条 | core_stories 的向量缓存 | 向量库 |
| `world/legendary.json` | 7.9KB | 9 replies + 8 confirms | **固定该怎么答**：正则触发 + 固定应答 + LLM 二判 | 否 |
| `world/terms.json` | 10.8KB | **27 个词条** | **懂词**：词/人物/梗的意思，命中才注 | 否 |
| `world/schedule.json` | 1.7KB | 7 条 | **地面真值**：她哪天几点播，每轮注入 | 否 |

> `persona/speech/` 目录**已空**——`phrases.json` / `voice_samples.json` 于 2026-10-04 拆掉并入库 `behaviors` 与骨架。

**四类数据 = 四种"记得"**：`schedule`（今晚播不播）→ `terms`（这词啥意思）→ `preferences`（她是怎样的人）→ `core_stories`（最深处的记忆）。详见 `架构.md` 注入层。

## 8. 按任务找文件（速查）

| 要改的 | 动哪个 | 改完要跑什么 |
|---|---|---|
| 她怎么说话 / 遇情境怎么反应 | `persona/core/system_prompt.txt`（骨架）、`persona/behavior/behaviors.json` | 重启 bot |
| 她知道某个词/某件事/某偏好 | `persona/world/terms.json` / `preferences.json` / `core_stories.json` | 改 `preferences.json` 只动 keywords，不重算；改 `core_stories.json` 后跑 `run_tool.py precompute core-stories` |
| 直播记忆（事实层） | `persona/world/statement_final.json` | 跑 `generate-vectors -i persona/world/statement_final.json` |
| 检索该不该命中 / 权重 | `src/plugins/chatbot/retrieval.py`、`constants.py` 的 `SOURCE_WEIGHTS` | `run_tool.py retrieval-eval`（**改语料会洗牌排名**） |
| 群聊接不接话 | `group_gate.py` / `constants.GROUP_GATE` | 重启 |
| 记忆（长期卡格式） | `memory_manager.py` + `constants.py` | `pytest tests/test_memory.py` |
| 语音 | `voice.py` | `pytest tests/test_voice.py` |
| 加了新表情包 | 丢进 `assets/stickers/` → `label_stickers.py` → 人工补 `group` | 重启 |
| 更新周表 | 根目录 `更新周表.bat` | 重启 |
