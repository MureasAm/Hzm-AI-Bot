## 一句话记住这个项目的四条判据

```
① 判据按任务选   归类→LLM分类 ｜ 关键词能说出口→子串 ｜ 说法不可枚举→向量+LLM判
② 形式看是否自足 自足→被整句抄 ｜ 碎片→被织进新句
③ 位置决定视角   紧挨用户那句→"刚发生过的事" ｜ 放前面→"参考资料"
④ 包装语管不住   想让模型怎么用，改形式，别加说明
```

（每条都有实验数据，见 `注入设计原理.md`）

> **文档时点规则（2026-10-01 起）**：同一结论出现冲突时，按文件内标注日期取最新；
> `文件体检结论.md` 中所有由 LLM 裁判得出的风格结论、以及 2026-09-30 后的风格标注集路线，
> 都只作历史记录，不得再用于决定人格文件去留。
