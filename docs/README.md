## 按"你现在要干什么"找

| 你要做的事 | 读这份 | 一句话 |
|---|---|---|
| **接手/继续这个项目** | **`交接文档.md`** ★ | 当前状态 + 下一步 + 卡住的东西。**下个会话先读这份** |
| 想知道"该改哪个文件" | `FILE_MAP.md` | 每个文件干什么，按"入口→运行时→人格数据→工具"组织 |
| 想知道**现在是什么样** | `注入链路.md` | 她有哪些素材、一条消息怎么被注进去、每层多少字符 |
| 想**改**检索/注入这块 | `注入设计原理.md` ★ | 判据怎么选、素材该长什么形式、每改一次是变好还是变坏（**带实验数据**） |
| 想跑某个脚本 | `脚本清单.md` | 38 个脚本各干什么；先看"实验/诊断工具"那节 |
| 想抽查她的回复 | `抽查清单.md` | 13 项指标翻成人话（**但推荐用 `spot_check.py` 自动挑**，只回答是/否） |
| 看还没做的事 | `待办清单.md` | 从全项目通读蒸馏的未完成问题 + "已判定不是问题、别再改回去"的登记 |
| 查历史 | `版本史.md` | V1.0→V7.8 每个版本改了什么、为什么、踩过哪些坑 |
| 看外部调研 | `调研-角色对话AI架构.md` | 2026-09-18 的三轮深度调研（业界方法 + 本项目处在哪） |

## 一句话记住这个项目的四条判据

```
① 判据按任务选   归类→LLM分类 ｜ 关键词能说出口→子串 ｜ 说法不可枚举→向量+LLM判
② 形式看是否自足 自足→被整句抄 ｜ 碎片→被织进新句
③ 位置决定视角   紧挨用户那句→"刚发生过的事" ｜ 放前面→"参考资料"
④ 包装语管不住   想让模型怎么用，改形式，别加说明
```

（每条都有实验数据，见 `注入设计原理.md`）
