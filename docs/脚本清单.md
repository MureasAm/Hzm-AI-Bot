# 脚本清单（55 个）

> 从每个脚本的 docstring 手工整理（**没有生成器**——原话写的"重跑生成器"是句空头支票；
> 加新脚本就照格式手加一行，并改这四个字面值：本节标题、`docs/README.md` 的索引行、`CLAUDE.md` 的两处、`docs/FILE_MAP.md` §一的 scripts 行）。

## 一、统一入口：`run_tool.py`

`python scripts/run_tool.py <工具>`——**日常改数据/跑评测走这个**。能跑 19 个子命令：

```
蒸馏   transcribe → clean-transcript → analyze-pace → convert-to-chat
生成   extract-persona / mine-phrases / mine-theme
向量   generate-vectors -i persona/world/statement_final.json ｜ precompute voice-samples|core-stories
评测   regression / persona-eval / retrieval-eval / problems / style-annotate
工具   bili-check / bili-login / vision-test
```

## 二、⭐ 实验/诊断工具（**改链路先跑这些**）

| 脚本 | 干什么 |
|---|---|
| **`trace_chain.py`** | 链路追踪：**对一条消息，把整条链的每个决策都打印出来。** |
| **`judge_experiment.py`** | 判别方法对照实验：**同一个任务，不同判据，谁最好用。** |
| **`form_experiment.py`** | 形式对照实验：**同一个事实，写成不同形式，看哪种传得进去、哪种会被整句抄。** |
| **`position_experiment.py`** | 位置对照实验：**同一段内容，放在 messages 的不同位置，会怎样。** |
| **`empty_turn_experiment.py`** | 空轮次实验：**六路都搜不到的轮次，给她垫一条风格样本，会不会更像她。** |
| **`entry_audit.py`** | 入口审计：**给每条素材造"用户会怎么说"，测判据能不能把它勾出来。** |
| **`persona_ablation.py`** | 消融实验：**拿掉某个注入段，她的回复变了吗**（`--sections` 一次检索试所有段）。 |
| **`persona_usage.py`** | 内容普查（**零成本**）：她 500+ 条真实回复里，用上了哪些文件的内容。 |
| **`schedule_ablation.py`** | 单段小实验模板：**合成问法 + 硬判据**，量某一段的单次作用（周表 → +88pp）。 |
| **`spot_check.py`** | 抽查自动化：**从聊天记录里挑出最值得看的几条**，你只需要回答"有没有明显不对"。 |
| **`threshold_scan.py`** | 阈值体检：量出每条检索路的「噪声地板」，据此定阈值。 |
| **`coverage_check.py`** | 覆盖度体检：拿真实对话跑检索，看有多少条"什么素材都搜不到"，以及各路命中率。 |
| **`problem_cases.py`** | **★问题驱动：看到的问题 → 回归用例。**先把检索实况摆出来，你再判该中/不该中。 |
| **`style_annotate.py`** | **★风格层标注集：出题（`风格标注.md`）→ 回读 → 出消融读数。**补上"像不像她"这层原来没有的判据。 |
