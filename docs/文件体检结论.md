## 负一、⭐ 统一标准：**一套流程，两种判据，由一个一句话的问题决定用哪种**

**先问这一个问题**：

> ### 「如果她把这句话说错了，我能指着说『这是错的』吗？」

| 回答 | 这类文件 | 判据（"算不算发挥作用"的定义） | 测试怎么做 |
|---|---|---|---|
| **能**（有客观对错） | **事实类**：周表 / 当前时间 / 世界(terms) / 偏好 / 经历背景(corpus) / 核心记忆 | **她答对了吗** | ① 挑（或造）"该用上它的问句" ② 同一批 messages 生成两版（有它 / 没它）③ 比答对率 |
| **不能**（没有唯一正确答案） | **风格类**：性格基底 / 语言风格 / 说话方式参考 / 行为指令 / 固定说法 | **哪一句更像她** | ① 同一句话生成两版（有它 / 没它）② 让裁判在**不知道哪版是哪版**的情况下挑 ③ 比"带它的那版"被选中率 |

**这就是能覆盖所有文件的标准。** 每个文件都能被归进上表的一格——**归哪格由那个问题决定，不由我拍**。

⚠️ **为什么不能只用一种**（这是前几轮反复失败的根因，也是本仓最值钱的一条方法教训）：
- **用"答对没答对"去测风格类** → 测不出。例：去掉【性格基底】后，她答的时间还是对的、事实还是对的 → 判据全绿 → 会得出"它没用"的**假结论**
- **用"哪句更像她"去测事实类** → 也测不出。例：去掉【周表】后她胡说一个时间，但胡说得很像她 → 风格判据全绿 → 同样得出**假结论**

**两类问题的性质不同，判据就不可能统一** —— 硬统一必然产出假结论。但**流程是统一的**：
`造/挑输入 → 只变一个变量 → 对照 → 比结果`，四步对每一类都一样。

## 零、怎么读这些数（**没有这一节就看不懂下面**）

下面用的**唯一**一个测试方式，说人话是这样的：

> **问**：把某个文件（或它的某一段）拿掉，她还像她自己吗？
> **怎么测**：拿几十句话，每句让模型回答**两遍**——一遍**有**那个文件、一遍**没有**。
> 然后让另一个模型只看这两句，回答"**哪一句更像灰泽满**"，而且**不告诉它哪句是哪句**（左右位置每次都打乱）。
> **结果**：统计它选"**有那个文件的**那版"的比例。
> **怎么读**：如果两版其实没差别，它瞎选也会有一半。所以——
> - **明显高于一半** → 那个文件确实让她更像她
> - **在一半附近** → **测不出差别**（可能真没用，也可能样本不够，两种情况分不开）

**为什么这么测**：直接给一句回复打"像不像她"的分是**不稳的**——同一句话两次生成，分数自己就能差很多。
但"**两句里挑更像的**"消掉了大部分这种抖动。而且这个裁判**先经过校准**：
拿"她的真话"对比"客服腔"，它 42 次里选对了 42 次——**先证明它真的分得出来，再用它做判断**。

⚠️ 另外两个词的区别（全文都按这个用）：
- **"在用"** = 代码有没有读这个文件（读了 ≠ 有用）
- **"有影响"** = 拿掉它，她的回复会变（**变了 ≠ 变好了**）
- **"有价值"** = 有它的时候，她**更像她**（上面那个测试量的是这个）

## 一、先读这节：**"绝对正确"做不到，但"可检验"做得到**

风格这类东西**没有标准答案**（"像不像她"没有唯一正确解）。所以任何声称"证明了这个文件有用"的说法都是假的。
能做的是三件事，这份文件每条结论都按这个格式写：

1. **证据强度分级**（说清这条结论有多硬）
2. **论证链**（假设 → 方法 → 数据 → 结论）
3. **它什么时候会错**（前提与反例）＋ **你自己复现的命令**

### 证据强度分级（本文件每条结论都标）

| 级别 | 满足什么才能给 | 能得出什么结论 |
|---|---|---|
| **强** | ① 判据有**客观真值**（答案在文件里，不是我编的期望）② 判据**能失败**（答错时确实不通过）③ **只变一个变量** ④ 差异**压倒性**（不是噪声） | 这个文件**在起作用**——可以当事实用 |
| **中** | 上述 ①②③ 都满足，但④样本小／话题少 | 方向可信，**大小**别当真 |
| **弱** | 判据是**代理指标**（没有客观真值），只能量"**影响**"不能量"**价值**" | 这个文件**在影响输出**——但**不等于它有价值** |
| **测不了** | 我的方法**覆盖不到**它（它不走"注入一段"这条路） | 别把它理解成"没用" |

⚠️ **"影响"和"价值"是两件事**，这份文件分开写：
- **影响** = 拿掉它，输出会不会变（风格类只能测到这个）
- **价值** = 有它比没有它**更好**（事实类能测：答对率）

## 一点五、★ 风格层缺的那个标准：**一个"标注集"**（用户提出，方向已确认）

对照三层就看出缺什么：

| 层 | 判定标准 | 谁定的 | 状态 |
|---|---|---|---|
| 检索层 | `scripts/retrieval_eval_cases.json`（这句话该不该命中） | 人 | ✅ 已有 |
| 生成层 | `scripts/regression_cases.json`（禁词/复读/同质） | 人（从真实翻车固化） | ✅ 已有 |
| **风格层** | **"像不像她"** | **？** | ❌ **没有** ← 这一轮反复翻车的根子 |

**我先前错在**：想找一个"裁判"来替人判（先是指标、再是指纹距离、最后是 LLM）。
**但"像不像她"的标准只能来自懂她的人**——所以正确做法是把它**固化成数据**，而不是每次临时判：

```
① 用户标注一批「这回复像她」的正例        ← 一次性
   （来源：chat_log 里她真实说过的 + 挑出来的生成样本）
② 之后所有风格类消融实验，都拿这批标注当**参照基准**：
   消融出来的两版，哪一版更接近标注里的正例 → **自动判，不用每次问用户**
③ 裁判既不是模型、也不是临场判断，而是「用户已经标过的数据」
```

⚠️ **别用向量相似度当那个"更接近"**：风格不是语义，"意思一样但不像她"的句子余弦可能更高。
   判定要用**用户标过的正例当对照**（人判 or 用标注集训出来的规则），不是 embedding。

**在它建起来之前**，风格类结论只有一种可靠做法：**左右打乱 + 不标注 → 用户盲判 → 复现两次**（本轮 traits/styles 就是这么测的：76% / 80%，两轮一致 89%）。

## 二点五、⚠️ 风格类读数**换过三次，前两次都废**（这段是给"怎么判断实验是否有效"的答案）

| 版本 | 读数 | 为什么废 |
|---|---|---|
| v1 | 长度/括号/叹号 | **指标没对准被测对象**（那是骨架管的，不是 traits/styles） |
| v2 | **指纹距离**（与她自己 620 条真实回复的距离） | **噪声 ≥ 信号**：baseline 两次运行自己就波动 **0.03**，而效应量 0.01~0.06 → **两版安慰剂给出相反判定** |
| v3 | **成对比较**（同一句的两个版本，问裁判"哪句更像她"） | ✅ **校准通过 42/42 = 100%**（她 vs 客服腔），位置随机 + 重复 + 二项检验 |

**v2 的教训（值得单独记）**：我给指纹距离配了两版安慰剂（一版用"关于她的真实陈述"当填充、
一版用中性占位），**两版给出的 ✅/❌ 几乎完全相反**。**判据是：两次运行的结果不稳定，
就说明读数在噪声里——不能拿它的结果下任何结论。**

**v3 的两条纪律**（缺一条结论就不成立）：
1. **先用已知答案校准**：拿「她的真实回复 vs 客服腔」测裁判 —— 必须几乎全选她。
   **校准不过关 → 读数废，别用它下任何结论**（v3 过了：42/42）
2. **报显著性**：只报"选中率 + 二项检验 p 值"，**不报孤零零的百分数**；50% 附近一律读作"分不出"

## 三、逐条论证

### ✅ `world/schedule.json`（周表，136 字，每轮注入）—— **强**

**结论**：在起作用。**没有它，她答不出直播时间。**

**论证链**：
```
假设：周表提供了"她哪天几点播"这个事实，而她自己不知道
方法：8 个问直播时间的问法 × 3 次 × 2 条件（同一批 messages，只删【灰泽满的周表】那段）
数据：有它 21/24 = 88%　｜　没有它 0/24 = 0%
结论：差 88 个百分点，且"没有它"是 0 —— 不可能来自噪声
```
**为什么这能支持结论（四道关都过了）**：

| 关 | 为什么过 |
|---|---|
| 判据有客观真值 | 答对 = 她说的**时间等于 `schedule.json` 里该天的值**。答案在文件里，**不是我觉得** |
| 判据能失败 | 没有周表时**确实 0/24**（如果判据是"提到播就算对"，两侧都会 100% → 那条就是废判据） |
| 只变一个变量 | 同一批 messages，**只删那一段**，其余一字不动 |
| 差异压倒性 | 0/24 vs 21/24，差 88pp —— 不是几个百分点的抖动 |

**它什么时候会错**：
- 前提假设是"她该答周表的值"。骨架里写着"被问直播安排**以周表为准**，不要拿旧安排当现在"——**前提成立**。
- 那 8 个问法是**合成的**（真实对话里只有 1 条问直播时间）。但判据与问法无关，所以"有没有用"的结论不受影响；
- **受影响的只有"多久被问一次"**——那决定"值不值得每轮注入"，**不决定"有没有用"**。

**复现**：`python scripts/schedule_ablation.py --runs 3`

**为什么只能是"弱"**：**没有客观真值**——"像不像她"没有唯一答案。
这里量到的是"**她变了**"，不是"**她变对了**"。
**它什么时候会错**：指纹是**代理**。它覆盖 8 个维度（自称/长度/括号/省略号/问号/叹号），
**捕捉不到"该嘴硬时嘴硬了没有"**——而那才是 behaviors 的职责。
→ **要测"价值"，得用行为正确性判据**（比如"被夸时她否认了吗"），那是下一步。
**复现**：`python scripts/persona_fingerprint.py --validate` 验尺子；`persona_ablation.py --sections`
